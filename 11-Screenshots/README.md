# 11 - Screenshots

Evidence screenshots for the lab writeups, one folder per module, named
`LabNN-<step>-<what it shows>`. Each writeup links to its own images.

Policy: a screenshot is kept only if it shows a **finding** (a rule firing, a query
result, a gap), not routine setup. New labs capture findings as they are run.
